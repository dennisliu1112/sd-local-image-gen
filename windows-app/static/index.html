關於模型量化（Z-Image Turbo）
目前內建 Q4_K ── 已是 4GB 顯卡的最佳平衡（速度 / 品質 / 顯存），不需更換。
• Q2_K（~2.6GB）：顯存不足時的後備
• Q3_K / Q4_K（建議，現用）（~3.7GB）：4GB 卡最佳
• Q5 / Q6 / Q8（4.5–6.6GB）：畫質略好，但需 6GB 以上顯存
同架構（Z-Image 系列）可把上方連結換成其他量化直接用；跨架構（FLUX / SDXL 等）需另外調整引擎參數。

進階 — 大型電腦解鎖 ⚡

⚠️ 以下是給高階電腦（大記憶體 / 大顯存）的選項。在一般電腦上開啟可能變很慢、甚至生圖失敗或閃退。預設值對小電腦最安全，沒把握就別動。
Q4 = 小、相容所有電腦（預設）；Q8 = 高品質、需更多記憶體/顯存。切換後若該模型尚未下載，請到上方「模型」區塊下載它。
×
解除一般上限，最高可到 8192px。8K 等級需要極大顯存/記憶體，失敗多半是記憶體不足。設定後會覆蓋上方的解析度按鈕，且只套用到這次工作階段。
